Piano From Above BETA

Version 1.0.1 • KaiOS 2.5 • Black MIDI supported • MIT License

A MIDI visualizer optimized for smart feature phones (Nokia 2720 Flip, 8000 4G, 6300 4G, 8110 4G, JioPhone...). Focuses on an optimized Canvas rendering pipeline to smoothly display high-density Black MIDI tracks on constrained hardware.

Key Features

  • Black MIDI Optimization - lightweight algorithms handle tens of thousands of notes without severe FPS drops.
  • Physical Keypad Support - smooth navigation via D-Pad and number keys.
  • Highly Customizable - full 128-key piano display, customizable track colors, adjustable note falling speeds.
  • WebAudio Synthesizer - built-in lightweight synth minimizes RAM usage on low-end devices.

Keys

  • < > seek ±1s • ^ v volume • OK play/pause
  • 1 +0.1x speed • 2 render mode • 3 -0.1x speed • 4 rotate
  • 5 load MIDI • 6 fullscreen • 7 keys 88-128
  • 8 clear MIDI (frees RAM) • 9 piano size • 0 stop
  • Call info card • * trail -0.1 • # trail +0.1 • End call quit
